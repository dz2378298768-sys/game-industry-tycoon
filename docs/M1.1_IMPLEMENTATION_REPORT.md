|---|---|---|---|
| R-001 | P0 阻断 | B7 改为「平均剩余生产完成度 × 50」；B8 修复比例改为 70%；最终总质量改为 `100 - defectLevel`；删除 40 / 0.8 / 200；五维质量作为原始快照单独保留 | `qa-quality.test.ts` 8 用例 |
| R-002 | P1 高 | GameWorld 与 ProjectService 均增加 `Number.isFinite` 检查，拒绝 NaN / ±Infinity / 0 / 负数 / >1 | `input-guards.test.ts` 6 类比例 |
| R-003 | P2 中 | 删除 Day 0 特殊放行，同日判定统一为 `currentDayIndex === dayIndex` | `input-guards.test.ts` Day 0 幂等 |
| R-004 | P2 中 | 疲劳只统计「岗位学科在该阶段可产出」的分配；跨岗位分配按休息恢复 | `input-guards.test.ts` 跨岗位疲劳 |
