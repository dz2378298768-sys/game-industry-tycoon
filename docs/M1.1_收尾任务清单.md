| 项 | 内容 |
|---|---|
| 任务编号 | TASK-M1.1-D01-001 |
| 名称 | D-01 连续暂停 60 天自动取消（底层逻辑） |
| 优先级 | P0（Δ-02：当前完全未实现） |
| 设计依据 | 交接文件 §4.3 D-01；08/01 状态机；DESIGN-M1-PAUSE-UI §5 |
| 前置依赖 | 可与 G-05-001-A/B 并行；UI 展示依赖本任务数据 |
| 修改范围 | Project 实体（pausedDays）、daily-scheduler、phase-rules、events、save-schema |
| 业务规则 | 进入 isPaused 累计完整游戏日；第59天仍暂停；第60天调度转 CANCELLED，reason='pause_timeout'；恢复/再暂停清零重算；超计划日不自动失败；取消后停研发/产出/新支出；存档保留计数 |
| 关键约束 | **禁止新增 PAUSED phase**；不自动恢复；与预算耗尽暂停共用计数（暂定） |
| 测试要求 | BDD：第59天仍暂停、第60天取消、恢复清零、再暂停重算、存档保留计数、取消后无产出 |
| 验收标准 | 92 用例不回归 + 新增用例全绿；typecheck/lint/build 通过 |
| 禁止事项 | 不改冻结 spec；不提前做 M2；不自动取消非暂停超时项目 |
| 完成回报 | 用 TASK-M1.1-G05-001.md §F 模板 |
