## 1. 出口条件（原文）

> 玩家能解释销量与现金流变化；≥2类定位产生不同结果（量化：两类定位 30 天销量差 ≥25%）。

## 2. 方法

| 项 | 取值 |
|---|---|
| 构造 | **生产工厂** `createGameWorld(seed)`（真实 content provider + 上市初始认知度） |
| 参数 | seed 42、单价 $29.99、平台 `arcade_pre_1975`、无营销、30 天 |
| 市场 | 1970：north_america / western_europe / japan（按开放年自动写入认知度） |
| 两定位 | 1977 同窗口：arcade_enthusiasts vs home_players，认知度统一 0.072 |
| 复现 | H06 **不固定随机产品 id**，跑两次逐字段对比 |

## 4. 修复内容（M2-H）

| 阻断 | 修法 |
|---|---|
| 无 `MarketInputProvider` | `src/content/market-inputs.ts` 权威表 + `createContentMarketInputProvider`；生产统一 `createGameWorld(seed)`；`store.init/load` 均走工厂 |
| 认知度无写入 | 上市按 `brand` 与市场开放年写入 0.02–0.12；旧档 `restore` 回填并留 `ProductLifecycleChanged(reason=awareness_backfill)` |
| 定位差不足 | 校准 `SEGMENT_PROFILE`：街机 0.6%/0.80、家用机 1.3%/0.55 → 36.37% |
| 同 seed 漂移 | 扰动键 `stableProductKey(name|genre|launchDay)`，不再用随机 product id |

## 5. 判定

| 出口条件 | 判定 |
|---|---|
| 玩家能解释销量与现金流变化 | **成立**：销量按市场×日可查，退款按批次可追，现金与流水逐分相等，合同结算比例可核对 |
| ≥2 类定位 30 天销量差 ≥25% | **成立**：36.37%（生产 provider，非夹具假数据） |
| 附带：同 seed 可复现 | **成立**（H06） |

## 6. 已知限制

- 旧档回填**不补历史销量与现金**，玩家会看到“从读档日起开始卖”；
- 定位与人口数值是设计初值，M5 经济校准要用真实曲线重调；
- 回填事件 id 含随机产品 id，事件 id 本身不可复现（不影响金额与复现性断言）。
