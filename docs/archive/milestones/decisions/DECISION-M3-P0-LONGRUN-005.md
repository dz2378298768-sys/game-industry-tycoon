# 规格：长期模拟与存活测试

- 编号：DECISION-M3-P0-LONGRUN-005
- 版本：v1.1（R1 修订后，R2 PASS_WITH_NOTES）
- 状态：**DECIDED**（编码在 M3-C）
- 上游：`spec/06/01 §3–§4`；`DECISION-M3-P0-ENDGAME-002`；`DECISION-M3-P0-AI-003`
- 目标：把「AI 公平、能长期存活、不垄断」变成可复现的报告，而不是观感

## 1. 运行口径

- 区间：1970-01-01 → 2026-12-31（约 20,800 天），至少 **8 个种子**（固定列表，含 42 作为基准）。
- 世界规模：玩家 1 家（可用脚本策略或空策略）+ AI 20–35 家，按年代分批入场（`TUNING.ai.entrySchedule`）。
- 频率：逐日推进；月度 AI 决策；年度快照。
- 性能预算：单种子全区间 ≤ 5 分钟（CI 用 3 个种子 + 10 年缩短版，夜间跑全量）。
- 输出：`artifacts/longrun/<seed>/summary.json` + `timeline.csv` + `report.md`，全部可重跑。

## 2. 指标（每个种子、每个年度）

| 指标 | 定义 |
|---|---|
| 存活率 | `active` 公司数 / 应存续公司数 |
| 破产率 | 当年进入 `bankrupt` 的公司数 / 年初 `active` 数 |
| 恢复率 | 当年 `bankrupt → active` 数 / 当年破产数 |
| 解散率 | 当年 `bankrupt → dissolved` 数 / 当年破产数 |
| 平均破产时长 | Σ(恢复日或解散日 − 破产日) / 破产事件数 |
| 市场集中度 HHI | Σ(各公司年净收入份额)^2，0–1 |
| 产品数量 | 当年在售产品数 / 公司数 |
| 策略差异 | 三类 persona 的 5 年存活率、平均净收入、破产率 |
| 玩家公平性 | 同策略克隆对照的逐字段差异（必须 0） |
| 事件频率 | 每年破产/恢复/解散/合同/退款事件数 |

## 3. 通过/失败阈值

| 判定 | 阈值 | 不通过的处理 |
|---|---|---|
| AI 全灭 | 第 20 年 `active` AI < 3 家 | 必须定位原因（现金/销量/成本），不得用全局倍率掩盖 |
| 单一垄断 | 第 20 年 HHI > 0.5 且连续 5 年上升 | 检查平台准入、内容供给、AI 预算上限 |
| 破产悬崖 | 任一年破产率 > 25% | 检查固定成本与现金储备约束 |
| 无恢复 | 恢复率连续 5 年为 0 | 检查恢复线（$4,000）与收入是否可达 |
| 玩家被碾压 | 同策略玩家克隆 10 年存活率 < AI 中位数 −20pp | 检查 AI 是否获得隐藏优势 |
| 不公平 | A03 对照出现任意非零差异 | 视为阻断缺陷（P1） |

## 4. 报告模板（必须包含）

1. 运行参数：种子、区间、AI 数量、策略脚本版本、commit hash。
2. 年度表：公司数、存活/破产/恢复/解散、HHI、产品数、平均现金。
3. 三类 persona 分箱：5/10/20 年存活率与净收入分布（P50/P10/P90）。
4. 异常清单：全灭、垄断、悬崖、零恢复，各附最早发生的年份与公司名单。
5. 公平性附录：克隆对照的逐字段 diff（必须为空）。
6. 结论：PASS / FAIL + 失败项定位到具体规则或常量。

## 7. R1 审查（v1.0 → v1.1）

- **P1-1 只写「观察」没有判定阈值**：没有阈值就无法 PASS/FAIL，长期测试会退化成看图。→ 增 §3 六条阈值。
- **P1-2 公平性对照没有纳入长期测试**：只在单测里比一次，无法证明 20 年不漂移。→ 增「玩家公平性」指标与 L01 反证。
- **P1-3 性能预算缺失**：20,800 天 × 35 家公司 × 每日销售，可能跑不动。→ 增 5 分钟预算与 CI 缩短版。
- P2：报告不可复现（无 commit/种子）→ §4.1；异常不得用全局倍率掩盖 → §3。
