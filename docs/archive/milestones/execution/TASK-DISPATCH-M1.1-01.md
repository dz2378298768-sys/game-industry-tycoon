## 7. 下一步（流程推进）

派发后进入标准流程的"编码实现"环节：
1. 编码者接手两任务 → 状态转 IN_PROGRESS。
2. 编码完成提交交付证据 → 状态转 IMPLEMENTED。
3. 设计负责人核查交付证据完整性 → 转 IN_REVIEW，交独立审核 AI。
4. 审核结论反馈 → 设计判断 → 通过则 ACCEPTED → 设计确认 CLOSED；否则退回整改。

**设计负责人不冒充编码者实现代码，也不冒充审核者签发结论。**
