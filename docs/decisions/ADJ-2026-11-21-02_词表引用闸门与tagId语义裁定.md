# 主 AI 设计裁定 — 词表引用闸门与 tagId 语义不可变

- 裁定编号：ADJ-2026-11-21-02
- 对应问题：D-04 词表包审核 C-01（E04 码未入闸门）、C-02（tagId 语义跨版本可变与旧存档失真）
- 裁定人：主 AI（项目总负责人）
- 依据：D-01 V0.2 §7.2.1 RevalidationGate；协作规范 §2.2E（一般设计取舍主 AI 裁定）；V3.0 基线 G4「不破坏旧存档」与 §13 可解释反馈
- 性质：DESIGN_BASELINE，可由试玩/模拟证据经规范 §8.2 修订

## 裁定一：词表引用解析为 RevalidationGate 的独立强制前置（C-01）

1. D-01 §7.2.1 的 `RevalidationGate` 在 `RunHardRules(S)` **之前**必须执行 `resolveRefs(S)`，校验 `ProductBlueprint` 中引用的 `SegmentTag` / `GameplayArchetype` / `Platform` 与当前权威词表版本一致（存在、非 deprecated、版本兼容）。
2. `resolveRefs` 失败产生的 `E04-DEPRECATED-TAG` / `E04-UNKNOWN-TAG` / `E04-DEPRECATED-PLATFORM` / `E04-UNKNOWN-PLATFORM` / `E04-UNKNOWN-ARCHETYPE` / `E04-NONACTIVE-ARCHETYPE` / `E04-DEPRECATED-ARCHETYPE` 一律并入 `violations`，按 **E 级硬违规**处理：禁止切换权威快照、禁止交付，并提供修正/撤销路径；完整 E04 码表以 D-04 词表包 §5.4 为准，D-01 §11 E-20 为非穷举登记（N-1 补全）。
3. D-04 规格必须区分「D-01 §11 的 E 码」与「本包 E04 码」，不得笼统写「复用上列全部 E 码」。
4. D-01 §11 规则登记表增加 E04 系列条目，TC-08a/08b 扩展覆盖词表引用失效场景。

**理由**：不把 E04 混入既有 E 码枚举而采用独立强制前置，既保留 D-01 已 DONE 版本的公式与规则结构，又使闸门覆盖新词表引用，避免编码 Agent 自行猜测。

## 裁定二：已发布 tagId 语义永久不可变（C-02）

1. 任何已发布 `tagId` 的取值与语义——包括 `displayName`、`dimension`、`granularity`、`eraRange` 及其在市场画像中的含义——**永久不可变**。
2. 跨版本只允许：新增 `tagId`；将既有 `tagId` 的 `state` 由 `active` 改为 `deprecated`。`deprecated` 拒绝新蓝图引用，但旧快照/旧存档中的引用继续按原语义只读解析。
3. 需要表达新语义时必须分配**新 `tagId`**，旧 `tagId` 保留以保证历史可追溯。D-04 §8.1 X-9 中关于同一 tagId 语义可变更的许可删除。
4. 该裁定使 D-04 的「不向快照增词表字段、只存引用」边界成立，满足 G4；无需落地版本绑定/词条快照方案。

**理由**：方案①以极低结构成本保证旧存档语义不漂移；方案②需要修改 D-01 快照结构并引入重放规则，超出 P1 最小词表包边界，且会拖累 P1 硬阻塞进度。

## 执行要求
设计 Agent 在 D-04 V0.2 中按本裁定关闭 R1/R2，并完成 R3~R6；原设计审核 Agent 复审。主 AI 已直接修订 D-01 §7.2.1，设计 Agent 不得并行修改 D-01。
