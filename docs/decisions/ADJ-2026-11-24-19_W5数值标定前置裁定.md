## 2. 通用纪律（W5 数值标定任务必须遵守）

1. **单位双写**：任何 cents/天/月/比例改动同时写业务值与代码值，例 $6,000 = 600,000 cents（CODEBUDDY.md §13.1）
2. **量级自检**：对照同文件既有同单位常量换算一遍（§13.4）
3. **禁用臆造**：C3 硬占位无权威数据支撑时保持 `NUMERIC_PENDING_P2` + OPEN 上报，不用“看起来合理”的数字填空
4. **参数快照**：定值后按 `formulaVersion` 生成快照持久化（D-02 §11 S9 / Project §11 S4 / D-03 §18.3），禁止重算历史存档
5. **回归验证**：每条定值用预研报告 §5 指定的测试文件 + 场景 Sx 验证，不空壳断言
6. **风险接受继承**：W5 九项核查须显式引用 RISK-01（07B-12 双轨闸门），不得宣称 UI 全链走通
