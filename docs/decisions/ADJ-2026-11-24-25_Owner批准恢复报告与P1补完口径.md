### 2.3 F-02 首个完整可玩版本范围 —— 采纳方案 A

- 首个可玩闭环验收包 = **一轮完整产品闭环 + 第二款产品决策入口**，即恢复报告 E 部分九步体验：
  创办公司 → 观察机会 → 设计第一款游戏（含 3–5 个玩法模块）→ 组建团队 → 组织研发 → 测试优化 → 交付与上市 → 销售结算与理解结果 → 经营调整与下一款产品决策。
- 不把 V3.1 G1 草案的「两轮完整经营且第一轮影响第二轮」设为首版门槛；两轮完整经营放在 REC-11 通过后的扩展验收。
- 完成定义锁定为：真机真 UI 由游戏体验 Agent 独立试玩通过、测试无手动写状态、至少两种定位产生可解释不同结果、玩家能复述产品表现前三个原因、四命令全绿且无未披露新增 BLOCKER/CRITICAL。
