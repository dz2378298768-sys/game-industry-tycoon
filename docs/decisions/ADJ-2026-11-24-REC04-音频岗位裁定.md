# ADJ-2026-11-24-REC04 音频岗位裁定

| 字段 | 内容 |
|---|---|
| 触发 | REC-04 自然推进测试发现音频 WP 无法完成 |
| Owner 决策 | 增加音频岗位，扩展 D-03 招聘与 ExecutionProject 产能 |
| 生效范围 | P1 可玩闭环、REC-04、D-03 `OPEN-D03-2` |

## 规则

1. 新增 `EmployeeRole = audio_designer`，对应 D-03 `audio` 学科。
2. 候选池从四学科扩展为五学科：`design/code/art/audio/qa`，仍使用原有确定性 seed、技能 0..5、薪资区间和候选池规模。
3. 音频员工沿用现有招聘费、月薪承诺、试用期、管理容量、存档迁移和离职规则。
4. `ExecutionProject` 的 team member 映射读取 `audio_designer` 的技能和分配比例，驱动 `Cap_audio` 与音频 WP；传统 legacy Project 的四学科阶段推进不变。
5. 旧存档不存在音频角色时不迁移出新员工；已有旧岗位和财务流水的语义不变。

## 验收证据

- `src/application/__tests__/rec03-project-creation.test.ts`：招聘五类岗位后，五学科 WP 均由自然日推进完成并进入 `READY_TO_DELIVER`。
- `npm run typecheck -- --pretty false`：通过。
- 定向 D-03、REC-03、UI 新项目测试：通过。
