# P1 收尾裁定

本次处理默认开局的营销效果、交付纠正说明和游戏日期。桌面复验同时补齐新交付档的三组质量读档证据。

| 项目 | 本次决定 |
|---|---|
| 营销购买意向 | 每天销售读取前一天已入账且未冲销的产品营销支出。销售和营销沿用现有结算顺序，未扣款的预算不参与。现有边际递减倍率只作用于尚有转化空间的受众，购买意向上限为 100%。已知晓度仍参与原有相对分配。 |
| 营销选择 | 交付默认不投放，玩家可以主动选低、中、高三档。每渠道日预算仍为 $100、$500、$1,500（10,000、50,000、150,000 美分），页面明确三个渠道分别投放和合计金额。产品页展示最近成交日所使用的前一日实付与新增购买意向。 |
| 窄众正式交付 | 清单从同一次评估读取当前与要求强度。玩家可直接进入设计修改并查看返工预估，仍须做完新工作并重新确认交付。E 级缺陷提供 QA 入口。 |
| 日历 | 显示采用模拟和账本原有纪元 Day 0 = 1970-01-01。开局、顶栏、立项年代、财务和复盘共用此日历，取代 ADJ-12 S1-3 和 ADJ-17 §2 的 2026 展示纪元；存档的日序、业务到账日、平台时间表及初始资金保持原值。旧档续玩时会用同一模拟日期显示。 |

同类型与客群只提高玩法强度时，单卖家销量是否应变化取决于后续质量如何作用于购买决策。P1 保持现行强度、研发成本、交付资格和市场需求关系。人才个人成长归因、默认竞品设定与归因历史持久化继续登记。
