# 主界面与美术主题设计 V0.1

2026-11-27。已确认布局与 UI 视觉方向。世界美术主题仍为提案。阶段范围与验收见[正式阶段基线](../baseline/02_版本路线图/01_开发阶段与验收门槛.md)。

## UI 视觉规范

街机面板为全局风格。深棕石墨底、琥珀主按钮、实体键面和分段进度灯用于工作室首页、顶栏和底部导航。危险、警告和完成状态同时用文字表达。产品目录、产品详情及其中的发行合同使用发行样刊的暖纸色、砖红、宋体标题与印刷分隔线。研发、团队、市场、财务与复盘遵循同一套导航和状态语义。交付、招聘、资金管理等操作走现有正式页面。

## 主界面结构

| 界面 | 玩家来这里做什么 | 布局与返回方式 |
|---|---|---|
| 工作室首页 | 看团队正在做什么，发现卡点，继续手头项目 | 居中呈现等距 3D 办公室。底部提供工作室、团队、研发、市场、财务入口。顶栏常驻日期、时间控制、现金与可用现金，提醒就近出现在对应工位或样机旁。 |
| 经营详情 | 分配员工、比较预算、处理合同、查看账本和产品表现 | 左侧展示当前经营领域及子页，右侧呈现详情、筛选与对照。详情保留全局底栏，返回工作室后恢复先前视角和焦点。 |
| 产业视图 | 了解地区市场、平台世代、竞品和历史变化 | 中央使用产业地图或时间线。地区、平台、事件和筛选信息沿屏幕边缘展开。选中对象后显示对应详情，关闭后保留选择与视角。随相关玩法成熟后接入。 |

工位打开实际项目团队和分配信息。试机台打开当前产品的缺陷、质量测试和交付入口。项目进度打开剩余工作和上市计划。热点随项目状态变化，例如缺程序员时指向补招或重新分配，有交付资格时指向交付。多个项目并行时，首页优先显示玩家选中的项目与需要处理的事项。

首个可验证切片采用一个房间、固定视角和上述三个入口，复用现有项目、人员和交付状态。所有场景入口也提供可由键盘操作的导航路径。办公室资产按房间、工位和关键设备逐步扩充。产业地图待跨区经营与历史数据具备可操作内容后再进入制作。

## 美术主题提案

**《游戏工业纪事》**。玩家从 1970 年代的一间街机研发室出发，通过工作室、团队、设备和产品档案，看到一家游戏公司如何成长，也看到整个行业如何变迁。

- **基调**采用写实比例的风格化三维场景。固定等距镜头、克制的光影和有年代感的材质，像能操作的微缩工作室。人物以清晰轮廓和有意义的工作动作表现岗位。
- **1970 年代开局**以旧木、米白塑料、深石墨和暖琥珀为主。道具围绕 CRT、手写设计图、测试用街机和零件箱。暖色聚焦在当前项目和下一步操作。
- **成长可见**。扩编后出现新工位和职能区，进入下一平台世代时替换或增添相应设备，产品上市后可在工作室陈列样机、产品包装或发售海报。场景变化以真实项目、团队和年代状态为来源。
- **年代演进**从早期木质街机与模拟仪器，走向主机与 PC 时代的模块化工位，再到后期的数字发行与远程协作设施。整体界面字体、导航位置和状态语义保持一致，年代主要通过空间、材质、设备和音乐表现。
- **详情页共享视觉语言**。办公室、经营详情和产业视图使用相同的状态色和文字层级。现金、进度和日期以易读的数字呈现，警告同时提供文字。品牌与道具采用原创设计，涉及真实历史的内容依照项目来源审查。

## 首轮体验验收

1. 玩家回到办公室后，能说出当前研发项目、下一步和需要处理的卡点。
2. 工位、样机与项目进度能分别打开真实状态与对应操作。完成招人、分配或测试后，返回首页能看到相应变化。
3. 研发、财务与合同支持直接比较。切换经营页、返回办公室和键盘操作均可完成。
4. 在窄窗口或关闭场景效果时，当前状态和关键操作仍可访问。

## 本轮实现与接线

- 工作室首页接入公司所在城市、当前在职人数、在研项目、计划上市和研发工作包。工位直接定位到所选项目的团队分配。样机在研发期打开测试，研发结束后打开交付，项目上市后可打开最新产品与发行合同。
- 经营详情接通项目、招聘、员工、市场、财务、产品和复盘。切回办公室保留所选项目。关闭 3D 时保留项目状态及同一组键盘可操作的入口。
- 浏览器已验证创建工作室、立项、两处热点定位、关闭 3D 后打开项目、保存并冷读、切换中英文。自动化集成从办公室样机进入交付，完成上市后再通过办公室进入产品详情和发行合同。
- 三维场景当前采用一间固定办公室，可视员工最多五人、样机最多三台。实际在职人数与项目列表仍显示完整数据。产业地图与跨年代资产按相应玩法阶段推进。
