# 游戏编辑器设计方案

玩家在立项前做出一款能看、能听、能试的样机。每次选择立即改变样机，玩家可以反复试验，直到找到想做的作品。确认企划后，再决定为它预留多少预算。

## 编辑流程

| 步骤 | 玩家做什么 | 当场能体验到什么 |
|---|---|---|
| 选起点 | 选品类和目标平台，从一套能工作的示例开始 | 中间立即出现可操作的样机，玩家可以先玩几秒再改 |
| 改玩法 | 换核心循环或加入一项特色 | 操控、胜负条件或局内目标立即改变 |
| 定画风与声音 | 换角色造型、色彩和音乐风格 | 同一段样机换画风，点试听即可用同一段动作比较配乐 |
| 配技术与画面效果 | 根据平台和工作室能力选工具、动画表现或命中效果 | 画面现场更新，右栏显示这次选择影响的岗位和工作量 |
| 对比并定稿 | 留一版作为对照，修改后在两版间切换 | 两版可分别试玩、看图和试听。确认后生成作品企划，再进入预算页 |

## 工作台

- **左侧选项**按玩法、美术、声音和技术分组。首作从完整示例开始，玩家可以只改最关心的一项。
- **中央样机**固定在同一个可重复试玩的短场景。画风、动画和画面效果立即更新，音乐与音效由玩家主动试听。切换方案时保留玩法进度或回到相同起点，方便比较。
- **右侧反馈**先显示“这次改了什么”，再显示岗位工作量、平台要求、已掌握能力和可能感兴趣的玩家。展现变动来源，能从同一次选择追溯到对应配置。

选项至少要提供可感知的变化。画面效果还应体现可读性等取舍，例如降低闪光强度后能更容易看清命中范围。样机展示按当前设计预期制作的效果。作品最终能否达到它，由研发、测试和交付结果决定。

## 画风、音乐、画面效果和技术的关系

| 选择 | 预览变化 | 接入经营或研发规则 |
|---|---|---|
| 画风 | 例如高对比剪影、少色像素角色。切换时保持当前动作和镜头 | 所选风格会改变美术工作量。受众偏好只有在接入内容规则后才展示 |
| 音乐风格 | 例如紧张的快速节奏、稀疏的电子旋律，播放同一局面供对照 | 依据配乐实现范围计算音频工作量。市场效果需要独立的受众依据 |
| 画面效果 | 例如命中闪光、受击顿帧，玩家能立即试出反馈差异 | 按效果计算程序和测试工作量，受目标平台与技术能力限制 |
| 工具与技术 | 例如精灵动画工具、音效编辑工具 | 读取现有科技研发结果。工具带来的工时减免进入立项估算。具备技术前提时才能定稿依赖它的选项 |

预览允许试用当前尚未掌握的技术，明确标出定稿需要补齐的条件。平台不支持时提供可落地的替代效果。预览、试听、撤销与方案对照都不花游戏资金。组队后再根据实际产能估算成本和日期。设计中的受众反馈用偏好方向表达，销量留到实际上市结算。

## 第一批可玩范围

先做一个 1970 年格斗街机样机，支持短局对战和两种核心玩法方向，两套画风、两套配乐和两档命中表现。具体风格、工时和技术前提由原型实际运行后校准。完成同一套流程后，再用共享工作台接入射击等品类。

比如在东京做短局格斗。玩家把角色换成高对比像素风，马上看到动作轮廓变清晰。再试听较快的配乐、试打开命中闪光。与上一版比较时，他能确定自己最喜欢的是角色更好辨认，还是命中更有力，也能看到后者需要额外的程序或测试工作。玩家可以带着这条取舍定稿。

首批复用立项向导的产品蓝图、平台准入、模块组合、岗位工作量估算和工作室研究。新增表现选项保存进企划，立项预览与研发拆包读取同一份配置。项目、交付和上市复盘沿用企划中的关键选择，形成从设计到成品的对照。

## 验收

- 玩家能在未立项时操作样机、切换画风、试听音乐、试验画面效果，并在两版间反复对照。
- 两个方案只改一项时，样机和右栏能看出这项改变。选择会影响工作量或技术门槛时，立项和研发也使用相同规则。
- 存读档后能恢复定稿企划，既有存档可沿用默认表现方案。
- 在进预算页前，玩家能说出作品是什么、自己刚才改出了什么、为什么保留这一版，并愿意继续试另一种组合。

## 品类与制作工作量

工作台共用选项、画面容器、试听、操作重放、撤销、A/B 对比和企划卡。样机按主要操作和目标复用。首批每个样机只有一段固定场景，格斗使用一名固定对手。

| 样机 | 两种核心玩法 | 品类独有的规则 |
|---|---|---|
| 格斗 | 防守反击、主动压制 | 对手起手、空档、防守和命中 |
| 射击 | 等待破绽、连续火力 | 横向走位、目标移动和护盾 |
| 益智 | 直达出口、取钥匙再撤离 | 网格障碍、钥匙和出口 |

两套画风、两套音乐、两档效果和两种核心玩法形成每个样机的 16 套基础组合。验收覆盖独立选项与互相影响的组合，制作时复用同一场景和控件。格斗、射击和益智现接入立项工作台，其他品类沿用已有立项流程。未来增加样机时，先确认它能让玩家试出新的玩法取舍。

工作量按实现范围区分。专属演出增加美术与测试量，动态配乐增加音频与程序量。现有技术工具决定能否采用相应表现，并参与工时减免。A/B 两版都能进入完整立项预览时，直接比较同一估算口径下的工时。资金不足或技术未齐时仍可试看，工作台展示选项的基础增量。

当前样机用简化的逐步输入演示核心规则。作品卡记录企划，保留到项目、交付、产品与复盘。真实销量仍从游戏的市场结算得出，样机选项已接入研发工时，音乐与画风的独立市场偏好留待内容校准。设计时撤销和保留的 A 对照属于当前工作台会话，正式企划随经营存档保存。
