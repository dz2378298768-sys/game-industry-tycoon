| B. 游戏体验与试玩测试 | **以等价角色实质启动**（W5 试玩验证子代理），但未以正式命名启动 | 理由、等价性与缺口见 §3 |

## 2. A. UI/UX 与美术总监 —— 不启动（正式角色）

**§5.2 适用条件对照**：
- "新的主要页面体系形成"：G1 是 07A/07B 对既有 M1.x 页面体系的接线收口，**未新建主要页面体系**，不满足。
- "整体视觉风格建立""UI 信息架构重大调整"：本阶段**未建立新视觉风格、未改信息架构**，不满足。
- "视觉表现或操作体验出现明显问题"：G1 试玩发现的是**功能接线缺口**（交付按钮无快照禁用），非视觉/操作体验问题；该缺口按 A 类编码问题处理（07B REVISION2），不属美术评估范畴。

**不启动原因**：G1 交付物是既有 UI 体系的功能完整化，不构成 §5.2 A 的启动触发条件；启动完整美术总监评估与当前工作无关，违反 §5.3"不得为完成流程而启动无关评估"。

**替代验证（§11.3"不能因不启动就取消必要质量检查"）**：
1. **U1~U6 六条 UI 口径**逐条实测通过（整体验收报告 §5）：三质量分列、跑道正确值、失败原因逐条、返工预估确认前、不展示 qualityCeilingBand、瓶颈高亮——这覆盖了美术总监关注点的"视觉信息清晰 / 交互逻辑"维度中本项目已有的硬约束。
2. **W4 批次集成检查**（`W4_批次集成检查报告_V0.1.md`）：对多系统页面完成后的统一检查（§5.2 A 触发项之一）已由集成检查覆盖。
3. **W5 试玩验证报告 §3**：U1~U6 以真实渲染 + DOM 断言复核，无视觉层级/布局/色彩类问题上报。

**保留缺口（诚实）**：本阶段**没有**独立《专项 UI/UX 与美术评估报告》，图标字体/色彩图表/美术表现等纯美术维度未做专项评估。若 P2 出现新页面体系或视觉风格调整，须按 §5.2 正式启动 A。

## 3. B. 游戏体验与试玩测试 —— 以等价角色实质启动（附缺口）

**§5.2 适用条件对照**："形成可运行的核心玩法闭环""多系统整合后需要验证整体体验"——G1 正是 P1 可玩闭环的验收阶段，**完全命中 B 的启动条件**。因此 G1 必须做试玩评估，不能跳过。

**实际执行**：派发 **W5 试玩验证子代理**，以真实可运行版本（`createGameWorld` 生产内核 + testing-library 真实渲染 + `fireEvent` 点击 + 真实 serialize/restore）执行：
- 上市全链实测（PATH-A：充足预算下 90 笔销售 / 574,026 件 / $11,474,779.74 收入入账）；
- 可玩闭环 10 步逐项判定（通过/不通过/无法验证）；
- U1~U6 口径复核 + RISK-01 披露；
- OPEN-S12-1 口碑回填可行性。

产出 `docs/review/W5_试玩验证报告_V0.1.md`（211 行，真实运行取证，非设计推演）。这**实质上满足** §5.2 B"该角色必须尽可能使用真实可运行版本"的要求。

**等价性与缺口（诚实）**：
- ✅ 实质等价：真机运行、独立执行（试玩代理与数值标定/编码代理互相独立）、证据精确到日志行。
- ⚠️ 形式差异：该代理**未以正式命名的"游戏体验与试玩测试 Agent"启动**，交付物也非名为《专项游戏体验与试玩评估报告》；且 §5.5 B 的评估重点中"玩家目标 / 决策质量 / 新手体验 / 挫败感与成长感 / 长期可玩性"等**主观体验维度未系统覆盖**——本次聚焦的是"闭环可达性"这一硬门槛。
- ⚠️ 结论消化：试玩发现 P-09 真实玩家路径走不通，经主 AI 裁定触发 RISK-01 失效 → 07B REVISION2 修复 UI 接线 → 独立复审 PWC；剩余 D-02 内核缺口如实标 NOT_VERIFIED，未以"B 评估通过"掩盖。

**处置**：G1 阶段不补做名义上的 B 报告（不虚构、不重复劳动）；P2 正式启动 B 时，须补齐主观体验维度与正式交付物命名。

## 4. C. 系统模拟与数值平衡 —— 不启动（正式角色）

**§5.2 适用条件对照**：
- "核心经济或市场系统完成""多个模拟系统完成整合"：G1 是 UI 接线与可玩闭环收口，**核心模拟系统在 M1.x/M2 已完成各自的设计审核与编码审核**，本阶段未新建经济/市场系统。
- "需要验证长期运行稳定性"：该验证以**回归测试**形式常态化执行（R9 同 seed 确定性、AI 公平性长跑 1~2 年、存档续跑），非本阶段新增的系统模拟评估。
- "出现经济失衡、数值膨胀或性能风险"：**出现了**——W5 数值预研与试玩揭示收入量级异常（$19.99 定价 30 天 $11.47M）、C7 预算帽相对 200 天 horizon 过小。但这被判定为**参数校准问题（P2）**，不属于"启动完整系统模拟 Agent"的范畴（§5.2："普通参数调整不需要启动完整模拟评估"）。

**不启动原因**：G1 的数值工作以"W5 数值专项标定"完成（见 §替代验证），数值失衡项已定性为 P2 参数问题并移交，无需再启动完整的系统模拟与数值平衡 Agent；启动将与既有标定工作重复，违反 §5.3。

**替代验证（§11.3）**：
1. **W5 数值标定实施报告**（`docs/coding/W5_数值标定实施报告.md`）：ADJ-19 八条 P0 逐条处置，C1 恢复线 $6,000 单一源收敛、C6 技能系数分域保留、C7/C3 定性裁定；1216 用例全绿（基线 1201→1216）。
2. **长期稳定性回归**：`ai-fairness-longrun.test.ts`（同 seed 双世界 1970→1972 两年指纹相等、存档副本续跑 1 年差异 0）、`w5-c7-default-ipo.test.ts`（逐日 200 天现金曲线）——这些是 C 的"长期数据变化/极端条件稳定性"检查的常态化替代。
3. **PATH-A 上市实测**：充足预算下 200 天推进 + 上市后 30 天销售，覆盖经济链路运行。

**保留缺口（诚实）**：本阶段**没有**独立《专项系统模拟与数值平衡评估报告》；"数值平衡"的专项结论（收入量级合理性、AI 企业行为深度评估）**未给通过结论**，PT-OBS-1/2 与 C7/C3 均带 P2。P2 数值校准轮须正式启动 C 或明确再次判断不启动的理由。
