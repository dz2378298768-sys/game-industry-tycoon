# P7 首发范围核对

截至 2026-11-27，首个可玩版已有 P1 内部验收记录。正式 1.0 仍有功能缺口和待验证项，发布门槛未满足。

## 适用口径

- [ADJ-25 §2.3](../decisions/ADJ-2026-11-24-25_Owner批准恢复报告与P1补完口径.md) 明确首个完整可玩版为一轮产品闭环加第二款决策入口。[P1 收口台账](P1_阶段收口与问题台账_2026-11-27.md) 保存内部验证证据。
- 正式 1.0 以 [V3.0 阶段门槛](../baseline/02_版本路线图/01_开发阶段与验收门槛.md) 和适用的已批准裁定为准。[V3.0 基线说明](../baseline/README.md) 明确旧版首发范围仅作历史参考。P3–P6 的既有核查覆盖核心运行基础。各阶段的必备条款继续有效。[P3–P6 核查记录](P3-P6_阶段核查报告_2026-11-27.md)

## 首发缺口与放行证据

| 阶段 | 可复用的现有基础 | 正式 1.0 尚需完成或验证 |
|---|---|---|
| P2 产品与市场 | 模块快照、购买意向、短期品牌记忆、模块方向继承和合同模板 | 走通同市场两套组合及双产品桌面路径，验证首款结果改变第二款经营，并明确自发行与真实报价的比较入口。补验冷读档后复盘归因，复盘页当前市场归因仍读会话缓存。补齐或裁定长期品牌、旧产品重新激活、市场扩张和营销承诺落差等条款。 |
| P3 AI 与合作 | AI 立项、推进、定价、营销、重整，另有玩家发行合同和账本结算 | 核验 AI 发行与资金决策、合作、谈判反报价、关系后果及基线所列合作场景。用多种子、多年代证明竞争分化和可恢复性。同种子复跑一致只覆盖确定性。历史 M3-C 记录的破产、集中度和内存问题需用当前构建复核。 |
| P4 全球与历史 | 地区数据、城市成本、平台准入和生命周期 | 补齐可玩的跨区扩张、技术研发与扩散、精选史实档案、可触发事件和可追溯的编年史，验证开局地区带来真实取舍。 |
| P5 人才与组织 | 招聘到岗、技能成长、薪资承诺和人员流动 | 补齐核心人才、导师、培养晋升、负责人及组织授权等必备条款，验证关键人才去留和扩张会改变经营结果。 |
| P6 长期经营 | 产品重复立项与销售，定价、折扣、退市、退款、合同和存档底座 | 补齐系列、续作、扩展、维护、长期技术与历史回顾。按 1、5、10、20 年及更长档验证不同路线的经营取舍、性能、存档增长和历史压缩。 |
| P7 发布验证 | 已有构建命令、存档校验与迁移测试，P1 有桌面路径记录 | 在候选构建上逐页验证新手引导、设置、速度、自动化与辅助功能、中英文、键盘和窗口适配。演练迁移和异常恢复，收集真人试玩并复测修复，交付性能报告、素材与历史内容审查、候选包和版本说明。 |

代码核对入口包括[复盘页](../../src/ui/pages/review.tsx)、[第二款向导](../../src/ui/pages/new-project.tsx)、[产品与发行页](../../src/ui/pages/product-detail.tsx)、[AI 决策器](../../src/simulation/ai/ai-planner.ts)、[平台和市场计算](../../src/content/c1-content.ts)、[人员服务](../../src/simulation/services/personnel-service.ts)和[存档校验](../../src/infrastructure/storage/save-schema.ts)。AI 长跑测试覆盖一年的存档克隆续跑和两年的同种子一致性。[AI 长跑用例](../../src/simulation/__tests__/ai-fairness-longrun.test.ts) · [历史长期模拟结果](../DEVELOPMENT-ROADMAP.md#1-开发里程碑)

## 可延期内容

旧版已列为延期的玩家平台、商业引擎、硬件经营、多人和复杂股权等未发现进入当前 1.0 的新裁定。大型扩展包编辑器和内容生产工具可留作后续工具批次，阶段基线要求的扩展玩法本身仍需验收。P3 合作与谈判、P4 技术与编年史、P5 导师与组织授权、P6 系列续作和扩展均有明确阶段要求。缩减这些条款需要正式范围裁定。[V2.1 历史延期清单](../../spec/01_产品范围/01_V2.1首发范围与延期清单.md) · [V3.0 阶段门槛](../baseline/02_版本路线图/01_开发阶段与验收门槛.md)

本次为文档与代码入口核对。真人试玩、性能和冷读档等运行结论以候选构建上的实际验证为准。
