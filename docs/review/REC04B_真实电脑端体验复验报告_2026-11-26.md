## 真实路径

1. 新档 Day 0（2026-01-05），创建 `REC04B 体验项目`。项目启动后账面现金 `$120,000`，可用现金 `$58,800`，与预算承诺提示一致。
2. 在招聘页选择美术师“候选人-0-3”（技能 5），确认卡显示中介费 `$2,002`、月薪 `$2,002/月`、预计 Day 3 到岗、候选有效至 Day 30。二次确认后，可用现金为 `$44,786`。
3. 招聘确认后招聘页显示“管理容量：0 + 1 待到岗 / 15”，并出现待到岗分组，显示岗位、Day 3 到岗日、月薪和“到岗前取消”。员工页显示 `员工 (0)`，月薪承诺 `$2,002`，学科产能缺口仍存在，证明待到岗没有提前生效。
4. 选择设计师“候选人-rec04a”（技能 5），确认后待到岗数变为 2，可用现金变为 `$33,551`。点击其“到岗前取消”后，页面提示“待到岗招聘已取消”，待到岗数恢复为 1，可用现金恢复为 `$44,786`，设计师候选重新出现在候选池。没有观察到取消对应的招聘费或遣散费交易。
5. 点击 `+30D` 推进到 Day 30（2026-02-04）。招聘页显示“管理容量：1 + 0 待到岗 / 15”；员工页显示美术师状态 `HIRED`，没有取消按钮。财务页交易流水显示 Day 3 入职成本 `-$2,002`，Day 30 工资 `-$2,002`，符合确认日预留、到岗日兑现和到岗月计薪的可见结果。
6. 项目详情中选择到岗美术师、投入比例 100% 并点击“分配”。页面提示缺少设计、程序岗位；`CAP_D` 中美术从 0 变为 5，团队区显示“已分配 1 人，日均产出约为 7 工作点”，同时列出已分配员工和“移除”按钮，证明到岗后可手动分配并产生产能。
