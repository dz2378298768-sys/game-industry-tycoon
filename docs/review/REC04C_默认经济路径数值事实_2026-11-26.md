# REC-04C 默认经济路径数值事实

## 结论

REC-04A 已解决五学科候选覆盖，但没有解决默认路径的经济与技能可行性。数值 Agent 用当前代码、默认资金 `$120,000`、默认项目容量 `$136,000`、HRB `45%`、先立项后招聘，在 10 个固定 seed 上复跑两种策略：

- 策略 A：每个学科选择最低报价的可用候选，一次招聘五人。
- 策略 B：每 7 天招聘一人，直到五学科齐全。

两种策略在 365 天内自然 `READY` 的完成率均为 `0/10`。策略 A 招聘后 `AvailableCash` 约为负 `$1,026-$7,258`，策略 B 约为负 `$6,616-$13,681`；五人招聘承诺（招聘费 + 六个月工资）约 `$59,826-$66,058`。部分低技能组合在预算耗尽/破产前无法完成工作。

## 解释边界

这是当前默认参数和当前候选技能生成下的事实扫描，不是设计结论，也不是通过调高初始资金后得到的可玩性证明。它没有修改起始现金、薪资、HRB、预算、六个月承诺窗口或 AvailableCash 公式，也没有把固定 Lv5 控制变量结果当作自然候选完成率。

## REC-04C 必须裁定

主设计负责人需要决定首项目的可玩策略：是否接受玩家先承担预算承诺、再选择低风险/低技能团队；是否需要首项目范围/技能门槛/候选报价呈现的引导；以及低技能失败应如何成为可理解的战略后果。数值 Agent 只负责对候选方案量化，不直接改锚点。体验 Agent 在裁定实现后验证玩家是否理解选择与失败原因。

在 REC-04C 裁定前，不得把“提高初始资金”“隐藏负 AvailableCash”“强制五名高技能员工”作为正式修复。
