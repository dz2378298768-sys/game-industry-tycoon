## 发现的问题

### P1：移动端布局严重溢出

复现：进入项目详情并将视口设为 390x844。页面出现水平滚动条；左侧导航仍保持约 160px 固定宽度，主内容被挤到右侧，产能卡片只能看到一列；顶部财务危机提示覆盖主内容。

影响：移动视口无法连续阅读项目详情或完成经营操作。

### P2：预算可行性空值显示为实现键（已修复）

复现：项目刚创建、尚未分配团队时打开项目详情。预算区域显示 `ratio / verdict: Infinity%`，并直接显示 `error.crisis.budgetOverrun`。

影响：用户看到内部错误键和无穷百分比，无法判断真实预算状态。分配团队后该区域恢复为正常的 `$30,366`、`49.6%`、`可行`。

修复：`project-detail` 对非有限 ratio 显示“暂不可估（缺少可用产能）”，不再格式化为 `Infinity%`；预算超支标签改用已登记的 `error.crisis.budget_overrun` 键。新增 canonical 缺岗回归用例，定向 UI 测试 5/5、`typecheck` 和 `lint:check` 通过。
