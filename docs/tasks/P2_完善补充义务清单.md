## 使用规则

1. 本台账是 Owner「记下并实行」要求的**执行载体**，每条义务对应一个明确缺口与验收标准。
2. 每条义务完成后须附**证据路径**（commit / 测试文件 / 真机取证），主 AI 逐条验收，不得自我声明完成。
3. **未完成义务不得因任何阶段关闭而免除**；阶段汇报必须携带本台账状态。
4. 优先级 P2 首位（SUP-01）是解除 G1 的 NOT_VERIFIED 披露 1/2 的前提。
