## 1. P2 总目标

把 G1 的"命令级/测试级可达"补齐为**真实玩家可玩**，并逐条撤销 5 条强制披露。不是新增玩法，而是**偿还 G1 欠账**——每条义务都对应一个明确缺口和验收标准，完成一条、验收一条、撤一条披露。

**三条硬约束**（来自 DP-1~4）：

1. 真实玩家路径，非夹具、非命令级；
2. 点击有可见反馈（成功有结果、失败有可读原因）；
3. 数值/快照由真实内核计算，fail-closed 只是过渡态，必须偿还。

## 5. 验收与披露撤销节奏

每条义务：`编码/裁定完成 → 主 AI 验收（证据路径）→ 编码类走双闸门独立审核 → 更新台账状态 → 更新披露状态`。

披露撤销映射（与义务台账一致）：

| 披露 | 解除条件 |
|---|---|
| 披露 1（真实玩家不能交付→上市） | SUP-01 验收通过 |
| 披露 2（UI 全链真点击未走通） | SUP-01 通过 + §四步骤 1–9 真实玩家路径全过 |
| 披露 3（定价档占位） | SUP-02 + SUP-05 |
| 披露 4（口碑无法回填） | SUP-03 |
| 披露 5（默认配置走不上巿） | SUP-04 |

**5 条披露在对应义务验收通过前持续有效**，任何阶段汇报必须携带。
