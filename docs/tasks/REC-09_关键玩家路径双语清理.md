# REC-09 关键玩家路径的双语显示

| 范围 | 处理与验证 |
|---|---|
| 主导航与推进控制 | 侧栏、时间速度与推进按钮在当前语言下取词。切换语言时同步文档语言，无需返回总览或重新加载。 |
| 立项向导 | 类型、平台、受众、工作量学科与模块摘要使用当前语言的目录或词条。立项拒绝从结构化错误码取词，已显示的正文错误随切换更新。 |
| 项目详情 | 类别、团队分配和取消分配、缺岗与推进、QA、等待计划上市、工资分摊和补救弹窗均用词条。项目名、员工名等玩家输入按原文显示。 |
| 复盘金额 | 净收入使用平台扣费后的销售额，减去已入账退款。待入账退款不从净收入扣除。 |

自动化在同一壳界面双向切换语言，检查导航、时间速度、立项选项及预算拒绝。项目详情路径覆盖推进提示变更与团队分配反馈，也检查姓名中的中文及特殊字符保持原样。译文键由词典一致性测试检查。

本轮验收覆盖以上关键路径。AI 公司名来自世界内容数据。已显示的跨页面历史 toast 仍是事件发生时的文本，词典切换适用于当前页面与后续提示。
