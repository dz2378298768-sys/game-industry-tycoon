# REC-10 市场数据与第二款入口

玩家从产品详情进入复盘，再回到市场页比较上款产品的类型与一项可选方向。可以从任一类型行进入正常立项向导，预填该类型。

| 玩家看到的内容 | 运行来源 | 数据边界 |
|---|---|---|
| 品类七日实销变化 | 当前世界全部产品的 `salesByPeriod.grossUnits`，按产品类型汇总。最新区间为当前已结算日及前六天，相邻七日区间作为对照。 | 新档满十四个模拟日且两个区间均有入账销量时展示。缺区间销量快照时显示信息不足。该值表示已履行的交易量，不直接预测未来需求。 |
| 品类与受众契合度 | 已发布的类型与消费者群体内容亲和表，继续使用原定定性阈值。 | 契合标签属于目录估算，不能替代实销比较。 |
| 当前对手 | `world.companies` 中已入场、未解散的非玩家公司。入场日和经营状态来自公司，在售数及最近发行来自已上市产品。 | 默认未启用 AI 竞争的存档显示空态。启用竞争的存档随真实进入、退出和产品发行更新。 |
| 上款和继承信息 | 最近上市的本公司产品、销量、扣除已入账退款的累计净收入、当前可用现金、当前可分配的团队角色及当前对手数。 | 上款是比较基线，另一项由玩家选择。产品档案经验待真实来源。第二款预算和人员继续受既有的公司状态与立项守卫约束。 |
| 已售产品的定位切片 | 上市产品的受众选择及销售记录，按地区与平台汇总毛销量。 | 未有记录保持空态。同一地区与平台的每日记录合为一行。 |

定向验证覆盖两个游戏世界的运行竞品差异、七日窗口边界、复盘的真实继承字段和带类型参数的第二款立项跳转。桌面端复验仍由体验 Agent 用真实上市结果进行。
