## 0. 结论速览（供主 AI 优先阅读）

**事实**：仓库代码的实际进度（`M3-C1` 阶段：C1 需求模型、M2 销售/退款/定价/营销/合同、AI 破产重整、终局解散均已落地；实测 **68 个测试文件**，166 个 `src` 下 `.ts/.tsx`）**显著领先** README 与 CODEBUDDY.md 的声明（README 自称 M1.1 / 12 测试文件；CODEBUDDY.md 自称 32 测试文件 / 230 用例）。证据：`README.md:L1-L6,L15`，`CODEBUDDY.md` §0，实测 `find src -name '*.test.ts' -o -name '*.test.tsx' | wc -l` = 68。**判断**：迁移分析必须以代码为准，不得以 README/CODEBUDDY 声明判断现状。

**最重要的 3 个工程阻塞**（详见 §4）：

1. **BLOCKER B-1 产品创造链路整体缺失**：产品创建仍是"选类型 + 填预算 + 选平台/受众"，另填 `name` 与 `launchOffset`（上市天数），但无蓝图/模块输入；`scope` 创建时为空、工作量由预算反推。D-01 的 `ProductBlueprint` / `BlueprintVersion` / `ModuleInstance` / `DesignVersionSnapshot` / 模板库与内容库**全部未落地**。证据：`src/ui/pages/new-project.tsx:L12-L35`、`src/simulation/services/project-service.ts:L61-L76,L121-L177`。
2. **BLOCKER B-2 权威边界与 D-01 正面冲突**：`Project` 同时持有 `genreId`、`scope: RangeItem[]`、`workTotalByDiscipline`，并在 `launch` 时直接产出 `Product`（一项目一产品）；D-01 要求 `Project` 仅引用不可变快照、不回写蓝图、估算为派生对象。证据：`src/domain/entities/project.ts:L19-L58`、`src/simulation/services/project-service.ts:L154-L162`、`src/application/mediators/game-world.ts:L1139-L1147`、`docs/design/01_...V0.2.md:L144-L174,L412`。
3. **BLOCKER B-3 质量与完整度模型冲突**：现有 `QualityProfile` 五维 + 单一 `finalQualityScore` / `defectLevel`，无设计质量、实现质量、完整度、市场匹配的独立表达；D-02 要求三者可分离。证据：`src/domain/value-objects/quality-profile.ts:L4-L14`、`src/simulation/systems/qa-quality.ts:L59-L81`、`src/domain/entities/product.ts:L26-L31`。

### 5.2 距离 V3.0 L0/L1/L2 分层模拟的缺口（判断）

基线 §4.1/§4.3 要求"每日交易与项目执行、月度企业战略、季度/年度产业结构与历史总结"、`结算周期按业务性质区分，不强制所有系统使用同一周期"。

- **L0（每日：交易与项目执行）**：已具备，且阶段顺序有明确因果注释（销售先于研发、`D+1` 才销售；退款紧随销售；营销/合同在退款之后以保证分成基数含冲减，`daily-scheduler.ts:L86-L104`）。**缺**：D-01 工作包依赖、关键评审、交付闸门；返工（设计变更）流程。
- **L1（月度：企业战略与财务）**：已有月末结算 + AI 月度决策。**缺**：玩家侧月度战略决策层（当前玩家操作全是命令式即时操作，无"月度战略"聚合）；应收应付/承诺支出对账（§2.3）；AI 合作/谈判（§2.19）。
- **L2（季度/年度：产业结构与历史）**：**基本缺失**。无季度结算、无年度趋势报告/战略复盘/编年史骨架（`isYearStart` 仅有方法无消费者）。**缺**：领域事件统一格式（D-07）、产业结构指标（集中度/平台更替/类型兴衰）、历史压缩与索引。
- **缺统一"结算周期注册表"**：当前周期散落在 `DailyScheduler`（日/月）与 `game-world`（月 AI），无"哪个系统跑日/月/季/年"的单一声明。建议在主 AI 裁定后建立分层调度契约（**OPEN**，不在 P0 编码）。
