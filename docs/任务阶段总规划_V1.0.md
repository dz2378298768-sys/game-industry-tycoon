## 5. 验收门槛（P1 / G1）

### 5.1 五道门（V3.1 §8.1）

设计验收 → 工程验收 → 界面验收 → 体验验收 → 模拟验收。G1 必须通过完整阶段验收；不是每个 L1 任务都要过五门。

### 5.2 P1 阶段否决项（出现任一即不通过）

1. "测试通过但功能不存在"路径；2. 恒真断言；3. 未标注旧口径残留（如仍按 ADJ-04/07 的 2 笔）；4. 规则套利（月末解雇省工资，ADJ-09 已封堵需实测）；5. UI 为掩盖内核缺陷做数值修饰（跑道乘系数）；6. 规格与实现不一致未登记 OPEN。

### 5.3 可玩闭环 10 步（主 AI 亲自操作，测试不可替代码）

新开一局 → 立项 → 组建团队 → 推进 → 设计变更（先见返工预估）→ 待交付 → 交付失败（逐条原因）→ 交付成功 → 上市销售 → 存读档 30 天一致。第 1~9 步任一走不通 或 第 10 步不一致 ⇒ P1 不通过。

### 5.4 UI 六条硬要求

U1 三质量分列；U2 跑道口径按 ADJ-11 修（**旧 U2"加口径说明"作废，改为直接展示正确跑道**）；U3 失败原因逐条；U4 返工成本确认前展示；U5 不展示 qualityCeilingBand；U6 瓶颈学科高亮。
