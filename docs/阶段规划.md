# 游戏产业大亨 · 阶段规划

截至 2026-11-27，**本地 P1 电脑版候选版已完成首款经营闭环的内部验收（PASS_WITH_NOTES）**。默认开局下，已实测立项、组队、研发、交付失败后返工、重新交付、上市入账、冷读档续玩和进入第二款立项。P1 候选实现另行同步；P2 尚未正式立项。

## P0–P7 正式路线

| 阶段 | 玩家体验和阶段出口 | 状态 |
|---|---|---|
| **P0 产品规则重整** | 统一产品目标、核心实体、规则权威和新旧规格的迁移边界。 | 已完成本轮基线整理 |
| **P1 单工作室可玩闭环** | 玩家独立经营一家工作室，完成第一款上市，理解销售与现金后果，再进入第二款决策。 | 内部验收通过，带登记事项 |
| **P2 产品与市场深度** | 相同类型的不同玩法组合形成可解释的受众和成本差异。第一款的经营结果影响第二款，品牌、竞品和生命周期开始产生长期后果。 | 下一正式阶段，未立项 |
| **P3 AI 产业生态与商业关系** | AI 企业靠同源规则做研发、销售、合作和重整决策。多个种子和年代能出现差异化竞争。 | 后续 |
| **P4 全球与历史世界** | 不同地区、平台和技术随时代变化，玩家能在不同开局条件下找到机会。产业大事可回溯到原因。 | 后续 |
| **P5 人才与组织成长** | 核心人才、负责人、导师和组织授权带来成长代价。培养和人员流动能影响项目。 | 后续 |
| **P6 长期经营与内容完善** | 多产品、系列续作、扩展和公司历史支撑多年经营，长档仍有取舍和稳定表现。 | 后续 |
| **P7 1.0 发布准备** | 验证新手引导、可访问性、存档恢复、性能和实际试玩，形成可发布版本。 | 后续 |

完整门槛见[正式阶段与验收基线](baseline/02_版本路线图/01_开发阶段与验收门槛.md)。P0–P7 用于验收，G0–G6 用于执行分组，M0–M5 用于追溯既有工程交付。

## P1 与 P2 的交接

- P1 已验证一款完整产品和第二款决策入口。研发完成、版本交付和正式上市是三个独立节点。
- 单产品营销已有实际效果。只提高玩法强度如何改变购买决策、跨产品品牌、市场竞品、个人成长归因和历史档案仍按台账跟踪。
- P2 的正式目标是把产品创造变成经营取舍。第一步可先锁定「同类型两套模块组合 → 同市场不同后果 → 第二款依据上款作出选择」这一段，再定玩法深度、市场与品牌的实现范围。此处为建议，未拆成已派发任务。
