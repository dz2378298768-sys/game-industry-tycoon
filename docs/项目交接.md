## 开发与打包

在仓库根目录运行 `npm ci` 安装依赖，`npm run dev` 打开开发预览。验收用 `npm run typecheck`、`npm run lint:check` 和 `npm test`，生产构建用 `npm run build`。

Windows 上运行 `npm run package:pc` 会重新生成候选 ZIP。本机包在 `artifacts/pc-build/GameIndustryTycoon-Windows-x64-TapTap-compatible.zip`，启动文件为压缩包根目录的 `GameIndustryTycoon.exe`。现有 ZIP 是添加游戏设计台以前的已验证候选包。体验本次交接的设计台请用源码开发预览，生成新包后需重新验证解压与启动。原包的校验值见候选包验证记录。原始长跑数据保存在 [2026-11-28 候选长跑记录](../artifacts/longrun/candidate-2026-11-28/)。

## 本次更新：游戏设计台

在「新建项目」点格斗、射击或益智的样机快捷入口。可以操作样机、换画风和效果、试听配乐、保留方案 A，并用同一组输入重放 A/B。高级选项受当前平台和工作室科技限制。作品定稿后，选择计入研发工作量并随经营存档保存。项目、交付、产品详情和复盘均可查看企划。

已在浏览器验证三种样机操作、画风切换、A/B、试听启动和企划定稿。自动化覆盖工作量进入研发拆包、技术门槛与冷读恢复。全量 1332 项测试、生产构建和 lint 通过。
