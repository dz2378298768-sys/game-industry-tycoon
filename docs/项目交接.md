## 开发与打包

在仓库根目录运行 `npm ci` 安装依赖，`npm run dev` 打开开发预览。验收用 `npm run typecheck`、`npm run lint:check` 和 `npm test`，生产构建用 `npm run build`。

Windows 上运行 `npm run package:pc` 会重新生成候选 ZIP。本机包在 `artifacts/pc-build/GameIndustryTycoon-Windows-x64-TapTap-compatible.zip`，启动文件为压缩包根目录的 `GameIndustryTycoon.exe`。包体不随 Git 同步。已验证的包体校验值见候选包验证记录。原始长跑数据保存在 [2026-11-28 候选长跑记录](../artifacts/longrun/candidate-2026-11-28/)。
