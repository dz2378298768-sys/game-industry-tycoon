AI 协作规范 V2.1 · 八角色体系 紫色 = 决策权 · 橙色 = 独立审核 · 标"按需"= 专项评估按需启动

主 AI / 游戏总设计师
统筹决策：规划拆分、裁定分歧、任务 READY/CLOSED、阶段验收。不得代替审核 Agent 出结论
设计 Agent
按任务书编写正式规格：数据、规则、状态、边界。不自审自关任务
设计审核 Agent
独立审规格：完整性、一致性、跨系统依赖、可验收性。八维清单
编码 Agent
按已批规格实现 + 写测试。不猜业务口径，规格歧义即上报
编码审核 Agent
独立跑测试、验业务规则、防作弊检查。不得仅凭编码自述判过
UI/UX 美术总监 按需
信息架构、交互流程、页面规格。必须输出可直接实现的规格
体验试玩 Agent 按需
真实走流程留证据。无可运行版本只能出静态评估
数值平衡 Agent 按需
经济循环、阈值标定、长期模拟稳定。不为数值漂亮破坏因果

核心工作流程 双闸门：未过设计审核不得编码 · 未过编码审核不得 CLOSED

主 AI 规划分级 + 任务书→ 设计 Agent编写规格→ 设计审核独立 · 八维→ 主 AI 置 READY闸门 ①→ 编码 Agent实现 + 测试→ 编码审核独立 · 反证→ 主 AI 验收闸门 ②→ CLOSED留档可追溯

任务分级 L1 / L2 / L3 L2 为默认流程

L1 轻量 简化流程
小修复 / 明确规则简单实现
可简化流程，但不跳过必要测试；发现风险超预期须上报重新分级
L2 标准 默认流程
一般系统功能 / 常规 UI / 规则调整
必须完整执行设计审核 + 编码审核双闸门
L3 重大 强化流程
跨系统 / 核心架构 / 经济规则
分阶段交付 + 专项 Agent 评估 + 回归测试计划（如 CODE-07）
