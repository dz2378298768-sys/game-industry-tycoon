# 核心经营循环

## 1. 设计目标

玩家不是每天点几十个按钮，而是在有限资金、团队时间、市场窗口和信息不确定性之间做取舍。模拟每日运行，但玩家主要在项目节点、每周摘要和月度经营会议中作决策。

## 2. 玩家持续追求的四种目标

1. **生存**：保持现金跑道，避免工资/合同违约和被迫停摆。
2. **产品成功**：做出符合目标市场需求的游戏，获得销量、口碑和利润。
3. **公司成长**：积累品牌、人才、IP、技术能力和稳定产品组合。
4. **战略身份**：成为精品工作室、类型专家、系列/IP公司或具备发行能力的厂商。

不设置强制胜利条件。动态目标提供方向，不限制沙盒自由。

## 3. 核心循环（单个产品）

1. **发现机会**：查看市场趋势、玩家偏好、平台用户、竞品上市计划和未满足需求。
2. **选择定位**：决定类型、目标受众、目标平台、产品规模、卖点和目标售价区间。
3. **立项取舍**：选择范围、质量目标、工期目标、预算上限和团队配置。系统展示三种估算：保守、基准、乐观，不承诺精确结果。
4. **组织生产**：配置设计/程序/美术/QA资源；调整范围、延期、加人或外包。任何调整都显示成本、工期和质量影响。
5. **质量闸门**：阶段评审、内部测试和QA决定缺陷修复量。玩家可选择按时上市、延期修复或缩减范围。
6. **商业化**：选择自发行或发行合作，设定定价、上市地区、营销预算和活动时机。
7. **市场反馈**：销量、退款、评价、口碑、品牌和现金流变化。报告说明前三个主要驱动因素。
8. **产品运营**：补丁、折扣、扩展内容（首发简化为一次可选内容更新）、停止投入或转入长尾。
9. **复盘**：比较预期与实际，记录成功/失败原因，影响下一项目的经验与公司能力。

## 4. 决策必须有代价

| 决策 | 短期收益 | 代价/风险 | 长期影响 |
|---|---|---|---|
| 扩大范围 | 更多内容与卖点 | 工作量、成本、延期、缺陷风险增加 | 成功时口碑/品牌上限提高 |
| 缩小范围 | 更快上市、降低预算 | 内容深度/市场吸引力可能下降 | 可能形成稳定小众产品线 |
| 增加QA | 降低缺陷与退款风险 | 延期或增加费用 | 品牌信任更稳定 |
| 提前上市 | 抢占市场窗口、早回款 | 缺陷/口碑风险 | 可能失去长期用户信任 |
| 延期打磨 | 提升稳定性/完成度 | 现金消耗、竞品抢先 | 高质量产品更有长尾潜力 |
| 自发行 | 保留收入和控制权 | 自担营销/渠道成本 | 建立发行能力和客户关系 |
| 签发行商 | 获得渠道、营销或预付款 | 分成、控制权和合同约束 | 可能加速扩张但利润率下降 |
| 高营销 | 提升认知和首发关注 | 成本高、转化不确定 | 成功产品获得更强品牌扩散 |
| 低价上市 | 降低购买门槛 | 单位收入低、品牌定位风险 | 扩大用户基数和系列受众 |

## 5. 时间节奏

- **每日**：项目工作量、销售、退款、合同到期、事件更新。玩家无需每日逐项确认。
- **每周**：提供一页经营摘要，显示项目偏差、现金预警、销售变化和待处理决策。
- **每月1日**：AI竞争者制定战略；玩家可进行月度经营规划。
- **月末**：工资、租金、服务费、合同、税费和应付款结算；显示现金流解释。
- **季度**：趋势报告、产品组合表现、市场份额和策略复盘。
- **年度**：公司年报、品牌/声誉变化、员工成长、目标和里程碑。

## 6. 避免微操

- 日常重复动作支持自动化策略：维持QA最低投入、按预算上限营销、自动处理小额补丁等。
- 自动化必须可查看规则、可暂停、可追溯，不得替玩家做高风险战略决定。
- 每日通知合并为摘要；重大风险和需要玩家选择的事项单独提示。
- 不要求玩家逐国逐平台手动设置每一笔日常操作。市场分组和默认策略可批量应用。

## 7. 失败与补救

失败必须先有预警。现金跑道低于阈值时显示预计可支付工资月份、可削减成本、可暂停项目、可寻求发行预付款等行动。项目延期时显示关键路径和可选范围削减。产品表现差时允许调整价格、追加有限营销、修复缺陷或止损。破产不能由一次随机事件瞬间触发。

## 8. 核心乐趣验收

垂直切片至少要证明：
- 玩家在一个项目中至少做出3次有明显代价的决策；
- 两种不同产品定位能产生不同的经营结果；
- 低预算路线与高质量路线都存在可理解的取舍；
- 上市表现能追溯到研发、价格、市场匹配和营销决策；
- 玩家在一次产品结束后有充分信息决定下一款产品，而不是只看一个总评分。
